# Thailand Travel Itinerary

A responsive, single-page travel-planning website built with plain HTML, CSS and JavaScript. No build tools or paid hosting required.

## Preview locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Publish free with GitHub Pages
1. Create a new public GitHub repository, for example `thailand-travel-itinerary`.
2. Upload `index.html` (and this README) to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. After GitHub Pages finishes publishing, your site will be available at:
   `https://YOUR-USERNAME.github.io/thailand-travel-itinerary/`

You can use that published URL in your Instagram bio.

## Customise
- Change text, prices and destination descriptions directly in `index.html`.
- The contact email and Instagram / YouTube links are already configured.
- Destination photos use direct image-file URLs from Wikimedia Commons and a diving operator's image CDN. They load over the internet, so visitors need an internet connection. Some Commons images have attribution/share-alike requirements; check each file's Commons page before reuse, and add the photographer/license credit if you publish or adapt it. Replace images with your own licensed photos whenever you like.

## Important transparency note
This is presented as an independent itinerary-planning initiative, not a travel agency or tour operator. The ₹30,000 amount is an indicative starting point, not a guaranteed all-inclusive price. Travellers book and pay providers directly.
